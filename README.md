# Materiały dydaktyczne

Repozytorium zawiera materiały do zajęć: notatki, przykłady kodu, pytania sprawdzające i zadania z różnych przedmiotów i zagadnień.

## Zawartość

Każdy plik `.md` to osobny temat. Przykładowo:

- [pdo-zamiast-mysqli.md](pdo-zamiast-mysqli.md) – PDO i zapytania parametryzowane zamiast `mysqli_*` (programowanie aplikacji internetowych, INF.03)
- [sesje-w-php.md](sesje-w-php.md) – Obsługa sesji w skryptach PHP: `$_SESSION`, logowanie, ochrona podstron, wylogowanie, bezpieczeństwo sesji (programowanie aplikacji internetowych, INF.03)
- [pliki-w-php.md](pliki-w-php.md) – Zapisywanie i odczytywanie plików w skryptach PHP: `file_put_contents()`, `fopen()`, tryby, `flock()`, CSV i JSON, bezpieczeństwo (programowanie aplikacji internetowych, INF.03)
